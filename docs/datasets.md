# Dataset provenance checklist

For every dataset used in AI-Photon, record:

- canonical dataset name and version;
- source URL or repository;
- license;
- modality and acquisition characteristics;
- number of studies/series;
- anatomy/pathology represented;
- whether labels are available and how they were produced;
- training/validation/test role;
- preprocessing applied;
- known domain-shift limitations.

Public sample volumes used by the current MVP are demonstration data and must not be interpreted as a clinical validation cohort.
